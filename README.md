## About
Real-Time Object Detection with YOLOv8 is a Python project that performs object detection on live webcam feeds using the YOLOv8 model. The project detects objects in real-time and displays them with bounding boxes and labels overlayed on the video feed.

## Features
- Real-time object detection from webcam feed
- Uses the state-of-the-art YOLOv8 model for detection
- Bounding boxes and labels on detected objects
- Easy to run and customize for different detection tasks

## Technologies Used
- Python (model inference and logic)
- YOLOv8 (Ultralytics)
- OpenCV (video stream and drawing)
- HTML (user interface)

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/ps982182/Real_Time_Object_Detection.git
   cd Real_Time_Object_Detection
   ```
2. Setup Python environment:
   ```
   python -m venv yolov8_env
   yolov8_env\Scripts\activate    # Windows
   source yolov8_env/bin/activate # Linux/macOS
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the object detection script:
   ```
   python detect.py  # or the main script for webcam detection
   ```

## Usage
- Make sure your webcam is connected.
- Launch the detection script.
- Detected objects with bounding boxes and labels will appear on the live video feed.
